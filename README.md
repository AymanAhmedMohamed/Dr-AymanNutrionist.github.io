# Dr.Ayman Nutritionist

## أهم ملف للتعديل
افتح `site-data.js` وعدّل بيانات الموقع كلها من مكان واحد.

يمكنك تعديل:
- اسم الموقع
- الاسم الظاهر
- وصف الموقع
- البريد الإلكتروني
- WhatsApp
- Facebook / Instagram / YouTube / TikTok
- عنوان ووصف الصفحة الرئيسية
- الإحصائيات
- قسم عن الموقع
- موضوعات التغذية العلاجية
- المقالات
- الأسئلة الشائعة
- التنبيه الطبي
- بيانات الفوتر

بعد التعديل ارفع الملفات إلى GitHub ثم Commit changes.

### هيكل الملفات
- `index.html` الصفحة
- `style.css` التصميم والألوان
- `script.js` وظائف الحاسبات
- `site-data.js` **كل البيانات القابلة للتعديل**
- `assets/` الصور والرسومات
